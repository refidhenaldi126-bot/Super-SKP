Kebijakan Privasi SUPER SKP

Terakhir diperbarui: 28 Oktober 2026

SUPER SKP (“Aplikasi”) adalah aplikasi web untuk membantu pegawai menyusun dan mendokumentasikan Sasaran Kinerja Pegawai (SKP) harian, lampiran foto, serta rekap triwulan. Aplikasi ini dikembangkan secara independen dan tidak berafiliasi dengan instansi pemerintah tertentu.

1. Data yang Kami Akses

Saat Anda masuk dengan Google, Aplikasi meminta akses terbatas ke data Google Anda dengan tujuan berikut:

  • Profil dasar Google (nama, alamat email, foto profil) — untuk menampilkan identitas Anda di dalam Aplikasi.
  • Google Drive & Google Sheets — untuk membuat dan mengelola folder “SUPER SKP”, menyimpan data kegiatan, foto kegiatan, serta file PDF/Google Docs laporan di akun Google Drive milik Anda sendiri.

Aplikasi tidak membaca, mengubah, atau menghapus file lain di Drive Anda di luar folder yang dibuat oleh Aplikasi.

2. Cara Data Digunakan & Disimpan

  • Data kegiatan, profil pegawai, tupoksi, dan foto disimpan secara lokal di perangkat Anda (localStorage dan IndexedDB) serta disinkronkan ke Google Sheets dan Google Drive milik akun Google yang Anda gunakan.
  • Pengembang Aplikasi tidak memiliki server yang menyimpan data pribadi atau file Anda. Semua data berada di perangkat Anda dan/atau akun Google Anda.
  • Foto kegiatan diunggah ke folder Drive Anda dan digunakan hanya untuk keperluan laporan lampiran SKP.

3. Berbagi Data dengan Pihak Ketiga

Kami tidak menjual, menyewakan, atau membagikan data Anda kepada pihak ketiga untuk tujuan pemasaran. Data hanya diproses melalui layanan Google (Drive, Sheets, OAuth) sesuai izin yang Anda berikan.

4. Retensi & Penghapusan Data

  • Anda dapat menghapus data lokal kapan saja melalui menu Akun di dalam Aplikasi.
  • Anda dapat menghapus folder “SUPER SKP” dan file terkait di Google Drive Anda sendiri.
  • Anda dapat mencabut akses Aplikasi kapan saja melalui pengaturan keamanan Akun Google (https://myaccount.google.com/permissions).

5. Keamanan

Aplikasi menggunakan autentikasi Google OAuth 2.0. Token akses dikelola secara aman di sisi klien. Karena data disimpan di akun Google Anda, keamanan juga bergantung pada praktik keamanan akun Google Anda.

6. Hak Pengguna

Anda berhak mengakses, memperbaiki, atau menghapus data yang terkait dengan penggunaan Aplikasi. Karena data berada di akun Google dan perangkat Anda, sebagian besar kontrol ada di tangan Anda.
